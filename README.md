# Mr.Cure Prototype

A front-end-only SIH prototype for rural healthcare coordination.

## Run
Just open `index.html` in a browser.

## Deploy
### GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, and `app.js`.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. Save and open the generated Pages URL.

### Netlify / Vercel
Upload the folder as a static site. No build command is required.

## Prototype flows
- Patient/Family: emergency request, care passport, referral tracking, public care, seasonal-risk guidance.
- ASHA/Health Worker: priority dashboard and voice alert.
- Hospital/Doctor: incoming emergency, pre-arrival information, readiness state, care passport.
- Emergency flow is simulated.
- Weather/health risk is demo content, not a clinically validated prediction.
- Patient data is demo data only. Do not use real patient information.

## Important SIH presentation wording
Say: "coordination layer around existing public-health and emergency services."
Do not claim the prototype replaces ambulance services, doctors, or government systems.
